API Core Endpoints

GET /health

Retrieves structured JSON diagnostics representing connection latencies and readiness profiles for Neon PostgreSQL, Upstash Redis clusters, and metadata settings.

Returns: {"status": "healthy", "database": {"status": "connected", "latency_ms": 2.5}, "redis": {"status": "connected", "latency_ms": 1.2}}
POST /api/v1/upload

Secure document ingestion gateway. Parses uploaded PDFs, extracts architectural & heritage metadata, executes semantic chunking, and saves records into the vector database.

Form-Data: file (file, binary) | api_key (text)
cURL Verification Script 
curl -X POST "http://localhost:8000/api/v1/upload" \
  -F "file=@/path/to/document.pdf" \
  -F "api_key=your_gemini_api_key"
GET /api/v1/health

A lightweight JSON status check matching routing standards for microservices and cloud health-checking systems.
